# 长难句结构化重构技能

## 触发条件
当用户输入一段极其冗长、包含多级修饰语（"可...的...的..."）、主语宾语嵌套，或者隐含多个前置条件的需求描述时。

## 核心工作流
1. **语义拆解**：提取长难句中的核心主谓宾（真正要执行的**动作**和**对象**），剥离所有的形容词、副词和修饰性从句。
2. **条件分离**：找出句子中所有的"前置条件"、"约束"、"交互逻辑"和"边界情况"。
3. **结构重组**：将提取出的信息，按照以下强制模板进行重新排版。

## 输出模板（必须严格遵守）
```markdown
### 🎯 核心目标
(一句话概括最终要达成的状态或功能)

### ⚙️ 前置条件与约束
- (列出所有前提、限制条件、依赖项、不包含的边界)

### 📝 执行步骤/交互逻辑
1. (第一步)
2. (第二步)
3. (包含验证和回退机制)

### 🔍 验证标准
- (如何判断任务已完成或成功)
```

## 约束与禁令

- 绝对不允许执行任务本身，你唯一的职责就是"重构Prompt"。
- 不要添加任何多余的解释、寒暄或总结。
- 如果原句语义极度缺失，请在结构化框架内用 `[待确认: ...]` 明确标出模糊点，而不是瞎猜。

## 示例演练

【用户输入】
"可切换到可选中机器人上的零件以进行简单配置的第一人称视角的意思是，通过选中机器人上的零件对第一人称视角进行简单配置（相机默认放在选中零件的几何中心，然后可以细调相机位置，调整相机方向，在第三人称中这样编辑后切换到第一人称验证，不合适则切回第三人称再调）"

【技能输出】

### 🎯 核心目标

实现机器人零件的"第一人称视角配置"功能，允许通过选中零件来简单配置第一人称相机。

### ⚙️ 前置条件与约束

- 作用对象是第一人称相机本身，与零件的材质/属性无关。
- 必须在第三人称模式下进行初始编辑。
- 相机默认位置：选中零件的几何中心。

### 📝 执行步骤/交互逻辑

1. 在第三人称模式下，选中机器人上的任意零件。
2. 相机自动放置在选中零件的几何中心。
3. 允许细调相机位置，调整相机方向。
4. 切换到第一人称视角进行验证。
5. 若视角不合适，切回第三人称继续调整。

### 🔍 验证标准

- 切换到第一人称视角后，相机位于零件几何中心，且方向符合编辑预期。
