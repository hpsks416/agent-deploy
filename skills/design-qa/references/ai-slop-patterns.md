# AI 味（AI slop）可判定清单

把「机器感」拆成可逐条判定的客观特征。评审时逐条打「命中/未命中」。

## 字体

- [ ] 标题/正文是 Inter 或系统默认字体（无定制字体）→ 命中
- [ ] 全站只有一种无衬线字体、无字重/字号对比 → 命中

## 配色

- [ ] 主色是紫→蓝渐变（#7c3aed/#8b5cf6 → #2563eb/#3b82f6 一类）→ 命中（最常见「AI 味」）
- [ ] 彩色背景上叠灰色文字（低对比度）→ 命中
- [ ] 全站只有紫/蓝两个色系、无品牌色 → 命中

## 布局与组件

- [ ] 一行居中大标题 + 上方小号大写字母标签（eyebrow）→ 命中
- [ ] 三张等宽卡片各配一个线性图标（landing 页模板）→ 命中
- [ ] 圆角卡片套卡片（card-in-card）→ 命中
- [ ] 每个标题上方悬浮一块圆角图标瓷砖 → 命中
- [ ] 卡片带 1px 细描边 + 柔和阴影（塑料感）→ 命中

## 改法（去味方向）

- **字体**：换有辨识度的字体（衬线标题 / 品牌字体），做字重字号层级。
- **配色**：去掉紫蓝渐变，换单一品牌色或高对比配色；不要彩色背景叠灰字。
- **布局**：打破三卡等宽模板，用不对称布局/真实内容密度；去掉圆角图标瓷砖，图标与内容结合。
- **阴影描边**：去掉「细线+柔影」塑料感，用真实层级（实色分隔 / 对比）替代。
