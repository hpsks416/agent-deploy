# Restricted Download → Mirror First（官方源受限下载止损）

## 与现有轮子的区别（铁律一已检索）

本机 skill 库无同类；GitHub 命中 `stm32pio` / `CubeMX2Makefile` / `micro_ros_stm32cubemx_utils` 均为**项目自动化**，不解决"拿安装包"；Gitee 搜索为空；官方中文站只回跳官网。判定：**自写**（固化一次真实踩坑的止损判据，证据见 `references/case-st-cubemx.md`）。

## 何时用

- 官网/官方源下载**点了没反应**、要求登录/注册、跳到异常页
- 官方直链 403（签名/登录墙）、下载中途反复被重置、返回拦截页
- 需要某商业工具的安装包镜像，或需要判断"能不能换开源替代"

## 何时不用

- 官方直链一次成功 —— 正常下载，别绕流程
- 只是查版本号、读文档 —— 走普通检索

## 硬规则（违反即失效）

**R1 三次停损（核心门控）**
同一官方渠道累计尝试 **≤3 次**。"换 UA / 换 Cookie / 换 http-https / Range 分片 / 断点续传 / 改用浏览器" 都算**同一次渠道的变体**，不重新计数；每次尝试记下「方式 + 结果 + 断点字节数」。
第 3 次仍失败 → **立刻停止**，进入镜像检索。禁止"再试一次"式无尽重试（实测：重试只会加深封禁）。

**R2 禁止用账号或高并发硬刚（封号成本 > 下载收益）**
- 不得用登录态脚本批量拉官方直链：账号被封的成本远高于一个安装包，且属于用户授权之外的代价。
- 不得开高并发（实测 32 路并发 → 直接被 WAF 封 IP，封后所有请求一小时内全部失败）。并发上限按 ≤4 理解；出现第一次重置就退回单线程。

**R3 拦截特征（命中任一条即视为失败，累计进 R1 计数）**
- 下载物变成**固定小体积 HTML**（如 7KB 级、标题空或"请求已被拦截"）替代安装包
- 同一 URL 反复在 **~0.5–1 MB** 处被 RST（Recv failure / Connection reset）
- **匿名 403 + 旧版 200**：说明新版改成签名/登录墙，旧版仍公开 → 走"官方旧版匿名 CDN"这一档

**R4 镜像优先序**（从可信到便捷）
1. 官方**旧版匿名 CDN**路径（改版本号试探同规律路径，HEAD 看 200/长度）
2. 官方中文站 / 官方社区公告（可能仍需会员登录，仅作为线索）
3. **版本合集帖**（CSDN/论坛的"历史版本合集"，常带 5 个网盘 + 提取码）← 国内环境命中率最高
4. 论坛附件 / GitHub-Gitee Releases（看是否为直链托管）
5. 网盘客户端（百度/夸克/UC/迅雷/城通）——只交付链接+提取码，不代下

**R5 开源替代优先（铁律一）**
任务本质是"用工具"而非"要这个包"时，先找开源等价物再做下载折腾。例：STM32 代码生成 → PlatformIO / 手工 HAL+CMSIS 模板 / embedded-hal 生态。能换轮子就不硬下。

**R6 必校验（不要交付未校验的二进制）**
- 下载前：HEAD 取 `Content-Length`；32 位 hex 的 `ETag` 通常就是整文件 **MD5**，记下来当校验基准
- 下载后：算 MD5/SHA256 比对；zip 再做结构校验（能列出条目、无 "Central Directory corrupt"）
- 网盘来源无法取官方校验值时，明确告诉用户"校验缺失"，并给本地校验命令

**R7 交付契约（给链接，不硬拉）**
产出必须包含：**文件名 + 直链/网盘链接 + 提取码 + 校验命令 + 风险提示**。
**>300 MB 不代下**：优先交付链接让用户侧下载；<300 MB 且来源可校验时才代下到工作区。

## 判定树

```
官方源一次成功? ──是──> 正常下载 + R6 校验，结束
      │否
      ▼
尝试次数 ≤3? ──否──> 停止（R1），报告已试方式与断点字节数
      │是
      ▼
命中 R3 拦截特征? ──是──> 停止官方向，进镜像
      │否
      ▼
任务本质是"要工具"? ──是──> R5 先评估开源替代
      │否
      ▼
R4 逐档检索镜像 → 拿到链接/提取码 → R6 校验 → R7 交付
```

## 脚本

`scripts/probe-and-verify.ps1`（本 skill 目录内，全部机械判定，勿手算）

```powershell
# 探测官方直链是否公开可用（HTTP 状态/长度/ETag=MD5/拦截页识别）
pwsh -NoProfile -File scripts\probe-and-verify.ps1 -Url '<url>'

# 校验已下载文件（大小 + MD5/SHA256，可选比对期望值）
pwsh -NoProfile -File scripts\probe-and-verify.ps1 -File '<path>' -ExpectMd5 '<md5>'
```

脚本只做机械判定并输出结构化结果，**是否止损、走哪档镜像由 agent 按 R1–R7 判断**。

## 交付模板

```
文件：<filename>（<size>）
来源：<mirror tier + URL>  提取码：<code>
校验：<md5/sha256>  命令：Get-FileHash <file> -Algorithm MD5
风险：非官方源，装前建议查毒；官方校验值 <有/无>
```
