# Directed Article Learning（定向学习文章 / 作者）

把一篇技术文章、或一位作者的「核心方法论」，结合**现有框架 + 当前项目**做「查缺补漏」。**不是摘要，而是把能补强框架或项目的点提炼出来并落地。**

## 触发方式

### 自动触发

用户说「定向学习 / 吸收这篇文章 / 学习这个作者」。

### 强制触发（标记语法）

- `《文章标题》` → 强制学习这篇文章。
- `--作者名--` → 强制学习这位作者（代表作 + 方法论 + 观点体系）。

只要输入里出现这两个标记，立即按本 skill 流程执行，不纠结「是否值得」。

## 何时不用

- 「学习领域」（如「学习 AI 领域」「学习量子位」）→ **不考虑**：范围过大，人类和 agent 都难以避免遗漏。
- 只是总结一篇文章 → 直接总结。
- 找现成项目 → `open-source-scout`。

## 学习对象 A：文章《X》

### 五步

1. **结构化提取**：`web_fetch` 拿正文（微信等有验证墙的，用 `web_search` 找 GitHub/arXiv/转载源）；提取是什么/核心机制/关键设计，不臆测。
2. **对照框架与项目**：文章核心机制对应框架哪个部分（skill/铁律/架构/部署/画像）？框架缺什么？**同时看当前项目（如用户正在做的项目）哪里能用上？**
3. **提炼缺口**：只提炼「能补强框架或当前项目的真缺口」，写清依据+落点；无关则 insights 给空（正确否掉也是有效产出）。
4. **三分类**：吸收（直接落地）/ 借鉴（适配后落地）/ 忽略（无关或已有更强）。框架缺口与项目缺口分别列。
5. **先申请落地**：输出「查缺补漏清单」，选项弹窗让用户勾选，同意后才改框架或项目。

## 学习对象 B：作者 --X--

1. **检索作者**：`web_search` 作者名 + 代表作 / 核心观点。
2. **定位代表作**：论文 / 技术报告 / 博客 / 开源项目，挑最有代表性的 2-3 篇。
3. **结构化提取**：作者的「核心方法论 + 思维习惯 + 观点体系」——贯穿其作品的一贯思路，不是单篇孤例。
4. **对照框架与项目**：作者的哪条方法论能补强框架的哪个部分、以及当前项目。
5. **三分类 + 先申请落地**：同文章流程。

## 取不到正文时的回落链（微信 / 验证墙 / 登录墙）

微信（`mp.weixin.qq.com`）经常返回 `环境异常，完成验证后可继续访问`；有的站点要登录。按**顺序**试，前一步失败才走下一步，**同一路最多试一次**，别反复硬撞：

1. **等价源检索**（首选）：`web_search` 用「标题全句 + 关键词变体」，找转载/镜像：BAAI 镜像（`hub-assets-cache.baai.ac.cn`）、36kr/虎嗅/掘金/知乎/腾讯新闻转载、arXiv 摘要页、GitHub README。
2. **读代理**：`https://r.jina.ai/<原链接>`（网络可达时能绕过 JS 墙；不可达就跳过，不重试）。
3. **请用户提供屏幕录制/截图**，用 ffmpeg 抽帧后逐帧读图转写：
   ```powershell
   ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1 <video>
   ffmpeg -v error -i <video> -vf "fps=1/4,scale=1400:-1" -q:v 3 <out>/f_%03d.jpg
   ```
   然后用 `read_image` 逐帧读（先用 1-2 帧判断字号是否可读，再决定抽帧间隔；帧间有重叠，按重叠处对齐句子）。
4. **请用户直接贴正文**（最可靠）。

**铁律**：

- **截图转写必须标注「可能被截断」**（行首/行尾常被切，例：「方形独立凸起块」只剩「型独立凸起块」）。
- **找不到等价源就不许猜内容**——写「未取到」，不要用标题臆测正文。
- 笔记里必须写清**取证方式**（走了哪一路、抽了多少帧），否则读者无法判断可信度。
- 三路都失败时，停下来问用户走 3 还是 4（选项弹窗），不要自造内容。

## 铁律

- 只提炼真缺口，不硬凑；无关则「无」。
- 先申请后落地。
- 三分类可判定，写清依据（文章/作者的具体机制），不凭感觉。
- 框架缺口与项目缺口分别标注，不混为一谈。
- 结构化提取借鉴 paper-to-agent-guide（Paper2Agent）的「结构/声明/方法」三层。

## 边界

- 学习对象 = 单篇文章 / 单一位作者。
- **不学习「领域」**（范围过大，易遗漏）。
