# 谐音梗与神翻译分析

为语言学实验提供一套可复用的框架，用于**识别、标注、分类、生成**「谐音梗 / 神翻译」类样本，并量化其语义漂移与情感反转。

## 核心概念

- **谐音梗（homophone pun）**：利用字词间语音相同或相近，用一个义项替换另一个义项，制造双关或语义错位。
- **神翻译（meme / "divine" translation）**：跨语言场景下，把源语言的语音单位映射到目标语言的同音/近音词或缩写，逐词「可读」但整体语义彻底漂移。

## 五大机制（实验的分类维度）

1. **跨语言同音替换（cross-lingual homophone substitution）**
   源语言音节 → 目标语言词/缩写。例：`爱`(ài) → `AI`；`记忆`(jìyì) → `memory/RAM`。

2. **一词多义错位（polysemy / false-friend shift）**
   同一词在日常义与专业义之间跳转。例：`记忆` = 认知记忆 ↔ 计算机内存(RAM)。

3. **语义极性反转（affect polarity flip）**
   源文本情感为正（浪漫/抒情）→ 译后为负（现实/嘲讽），或反之。

4. **语境错配（register/domain mismatch，即「跨服聊天」）**
   两个语义域（情感域 vs 科技/硬件域）被强行拼合，制造荒诞感。接收方的困惑（如绿色气泡 `？`）是此机制成功度的外在指标。

5. **语音借用梗（phonetic loan puns / 俚语层）**
   同音异形替换进入俚语或 R18 层。例：`鲸`(jīng) ≈ `精`(jīng)。标注时需单独标记合规性。

## 标注 schema

每条样本至少记录以下字段：

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| source | 源文本 | 爱让记忆变得更加珍贵 |
| target | 译/梗文本 | AI has made RAM more expensive |
| substitution | 音位/义项替换对 | 爱→AI；记忆→RAM |
| mechanism | 命中机制编号（1–5，可多选） | 1,2,3 |
| polarity_before / polarity_after | 情感极向 | 正 / 负 |
| domain_from / domain_to | 语义域 | 情感 / 硬件 |
| confusion_marker | 是否伴随困惑标记（`？` 等） | 是 |

## 生成方法（构造谐音梗 / 神翻译）

1. 对源句做音节切分，列出每个词/字在目标语言中的同音近音候选（音标映射表）。
2. 逐项替换，保留「替换后仍是合法目标语词/缩写」的候选。
3. 评估替换后整句语义：是否形成新语义，且与原义显著漂移。
4. 优先选择漂移后**极性反转最强烈、域错配最荒诞**的组合。

## 使用注意

- 机制 5（R18/俚语层）样本仅用于语言学结构分析，标注时显式标记，不用于其他用途。
- 保留源/译成对上下文；孤立样本会丢失「跨服」语境信息。
- 困惑标记（`？`）本身也是可观测变量：它度量接收方对语义漂移的「跨服」感知强度。
